# Artwork Credits and Inspiration

## Project

Expressive Emojis is independently maintained by **alcalogica**.

## Historical inspiration

The project is inspired by the expressive style of classic animated internet emoticons.

## AI assistance

ChatGPT and generative AI have been used to assist with new visual interpretations, rendering, animation and refinement. Some creations use historical emoticons as visual references.

## Third-party rights

No ownership is claimed over original third-party reference artwork. Generic expressions and gestures are not claimed as exclusive property of this project.

Where a creation reproduces protected third-party expression, any necessary permissions must be established before redistribution. Attribution alone does not replace permission. The project license covers only eligible contributions for which the maintainer holds licensing rights.

## Contact

If you recognize original artwork or have information about its authorship or licensing, please open an issue at https://github.com/alcalogica/expressive-emojis.
